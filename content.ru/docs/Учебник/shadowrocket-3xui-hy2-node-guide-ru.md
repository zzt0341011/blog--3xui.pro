Если вы уже привыкли к клиентам вроде Shadowrocket, рано или поздно появляется
мысль «а не поднять ли свой узел» — либо потому что не хочется зависеть от чужого
сервиса, либо потому что хочется настроить все параметры под себя. Это описание
полного процесса создания узла Hysteria2 (HY2) на собственном VPS с помощью
open-source панели [3X-UI](https://3x-ui.pro/ru) и включения port hopping — от покупки машины до рабочего
подключения клиента.

## 1. Зачем поднимать свой узел

По сравнению с использованием готового сервиса от кого-то другого, у
самостоятельного хостинга есть несколько явных плюсов:

- **Вы контролируете каждый параметр**: протокол, порт, метод обфускации,
  сертификат, лимиты трафика — всё настраивается под ваши нужды, а не по чужим
  правилам.
- **Не нужно беспокоиться о внезапном ограничении скорости или отключении**:
  машина и панель принадлежат вам, поэтому стабильность зависит только от самого
  VPS и вашего обслуживания — сценария «провайдер решил остановить сервис» просто
  не существует.
- **Легко масштабируется по горизонтали при необходимости**: одна панель может
  одновременно управлять несколькими входящими подключениями и несколькими
  клиентами, что удобно для разделения узлов по назначению и самостоятельной
  диагностики.

Конечно, у самостоятельного хостинга есть и своя цена — нужно самому купить
машину, самому поддерживать панель и продление сертификата, самому разбираться с
проблемами. Стоит ли оно того — зависит от того, сколько усилий вы готовы вложить.

## 2. Преимущества протокола Hysteria2

Hysteria2 (HY2) стал довольно популярным в последние годы. Вот несколько его
ключевых особенностей:

- **Построен на QUIC, устойчив к потере пакетов**: работает поверх UDP + QUIC,
  поэтому на нестабильных соединениях с высоким процентом потерь пакетов обычно
  стабильнее, чем традиционные протоколы на базе TCP.
- **Высокий потолок скорости**: протокол оптимизирован для сценариев с высокой
  пропускной способностью, поэтому хорошо себя показывает при максимальной
  загрузке канала или передаче больших файлов.
- **Поддерживает port hopping**: клиент и сервер могут динамически переключать
  реальный используемый порт в пределах заданного диапазона портов, что помогает
  снизить вероятность целенаправленного ограничения скорости или блокировки.
  Именно на этой части мы сосредоточимся дальше в статье.

### 3.2 Купить домен

Домен понадобится для получения сертификата узла. Я купил свой на
[Porkbun](https://porkbun.com/) — интерфейс простой, а продление недорогое, но вы
можете выбрать любого регистратора, к которому привыкли.

### 3.3 Направить домен на IP вашего VPS через Cloudflare

После покупки домена зайдите в Cloudflare и добавьте A-запись, указывающую домен на
IPv4-адрес вашего VPS. Тип выберите `A`, в качестве имени укажите префикс поддомена
(как `toto` на скриншоте ниже), а статус прокси оставьте выключенным (только DNS,
без проксирования через Cloudflare) — иначе позже это помешает получить сертификат
Let's Encrypt.

![Добавление A-записи в Cloudflare, направляющей домен на IP VPS](https://shadowrocket.ink/img/3x-ui.jpg)

### 3.4 Проверить доступность через ping

После того как DNS-запись распространится, сначала выполните `ping` до IP VPS
локально, чтобы убедиться, что задержка и потеря пакетов в норме, прежде чем идти
дальше.

![Ping IP-адреса VPS из командной строки для проверки связи](https://shadowrocket.ink/img/3x-ui-11002.jpg)

### 3.5 Подключиться к VPS через удалённый инструмент

Далее используйте FinalShell (или Xshell, iTerm — любой привычный инструмент),
чтобы создать новое SSH-подключение: хост — IP вашего VPS, порт по умолчанию 22,
имя пользователя `root`, а пароль — начальный, полученный на странице покупки.
После подключения можно приступать к настройке окружения.

![Создание нового SSH-подключения в FinalShell для подключения к VPS](https://shadowrocket.ink/img/3x-ui-11003.jpg)

## 4. Установка 3X-UI

3X-UI — это открытая веб-панель управления для сервиса Xray-core. У неё
дружелюбный многоязычный интерфейс, и она позволяет управлять несколькими
протоколами и несколькими входящими подключениями из одной панели — гораздо
удобнее, чем работа через чистую командную строку.

![Страница описания проекта 3X-UI](https://shadowrocket.ink/img/3x-ui-11004.jpg)

### 4.1 Команда установки

После подключения по SSH к VPS обновите систему, установите зависимости, а затем
запустите официальный скрипт установки:

```bash
apt update -y
apt install -y curl socat
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

Скрипт установки по очереди задаст несколько вопросов:

- **Тип базы данных**: если клиентов будет немного, стандартного SQLite вполне
  достаточно.

![Скрипт установки спрашивает тип базы данных, по умолчанию SQLite](https://shadowrocket.ink/img/3x-ui-11005.jpg)

- **Настраивать ли порт панели вручную**: если оставить пустым, будет
  сгенерирован случайный порт; из соображений безопасности лучше задать порт,
  который сложнее угадать.

![После выбора базы данных скрипт спрашивает, настраивать ли порт панели](https://shadowrocket.ink/img/3x-ui-11006.jpg)

- **Настройка SSL-сертификата**: здесь есть несколько вариантов. Поскольку домен
  уже настроен, проще всего выбрать «получить сертификат Let's Encrypt для
  домена» — сертификат будет продлеваться автоматически.

![Меню настройки SSL-сертификата с несколькими способами получения](https://shadowrocket.ink/img/3x-ui-11007.jpg)

После выбора этого варианта введите домен, который вы настроили ранее, и скрипт
автоматически запросит сертификат:

![После выбора варианта с доменным сертификатом введите свой домен](https://shadowrocket.ink/img/3x-ui-11008.jpg)

После выпуска сертификата скрипт выводит пути к сертификату и приватному ключу и
спрашивает, хотите ли вы изменить `--reloadcmd` (команду, которая автоматически
перезапускает панель после продления сертификата) — в большинстве случаев подходит
значение по умолчанию:

![Сертификат успешно выпущен, скрипт выводит путь к сертификату](https://shadowrocket.ink/img/3x-ui-11009.jpg)

После этого скрипт также настраивает fail2ban (защиту от перебора паролей) и
показывает меню управления с типовыми операциями: запуск, остановка, перезапуск,
просмотр текущих настроек:

![Меню управления, появляющееся после завершения установки, с опциями запуска/остановки/перезапуска](https://shadowrocket.ink/img/3x-ui-110091.jpg)

Прокрутив меню дальше, вы найдёте управление сертификатами, управление
файрволом, включение BBR, тест скорости и другое, а состояние работы панели и
Xray отображается внизу:

![Остальная часть меню управления, включая управление сертификатами, файрвол, BBR и тест скорости](https://shadowrocket.ink/img/3x-ui-110092.jpg)

Выбрав «просмотр текущих настроек», вы увидите порт панели, путь к базе данных и
адрес доступа — запишите их, они понадобятся для входа в панель на следующем шаге:

![Просмотр текущих настроек панели, включая порт, путь к базе данных и адрес доступа](https://shadowrocket.ink/img/3x-ui-110093.jpg)

Откройте панель по адресу доступа из предыдущего шага и войдите с именем

![Страница входа 3X-UI](https://shadowrocket.ink/img/3x-ui-110094.jpg)

После входа на главной странице видны загрузка CPU и памяти, а также статус

### 4.3 Создание входящего подключения HY2

Вернитесь во вкладку «Входящие» в боковой панели и нажмите «Добавить входящее».
Выберите протокол `hysteria` (то есть Hysteria2), укажите любую понятную вам
пометку и задайте порт по своему выбору:

![Диалог добавления входящего, протокол выбран как hysteria, указаны пометка и порт](https://shadowrocket.ink/img/3x-ui-110098.jpg)

В настройках транспорта можно добавить UDP Masks (обфускацию трафика) — выберите
тип Salamander (встроенная обфускация Hysteria2), сгенерируйте случайный сложный
пароль и выберите алгоритм контроля перегрузки BBR:

![Настройки обфускации UDP Masks, тип Salamander, контроль перегрузки BBR](https://shadowrocket.ink/img/3x-ui-110099.jpg)

Ключевая часть здесь — переключатель **port hopping** ниже: включите «UDP Hop»,
укажите диапазон портов (например, 20000-50000) для перескока и задайте интервал
переключения (например, 5-10 секунд). Клиент и сервер будут динамически менять
реальный используемый порт в пределах этого диапазона с заданным интервалом:

![Включение port hopping UDP Hop с диапазоном портов и интервалом](https://shadowrocket.ink/img/3x-ui-1100991.jpg)

На вкладке безопасности установите «Безопасность» в значение TLS, укажите свой
домен в качестве SNI и выберите `h3` для ALPN (поскольку Hysteria2 построен на
QUIC/HTTP3) — остальное оставьте по умолчанию:

![Вкладка настроек безопасности с параметрами TLS, SNI и ALPN](https://shadowrocket.ink/img/3x-ui-1100992.jpg)

В разделе сертификата просто укажите пути к сертификату и приватному ключу,
полученным ранее от скрипта установки (по одной строке для публичного и приватного
ключа), затем сохраните:

![Настройки цифрового сертификата, ввод путей к файлам сертификата и приватного ключа](https://shadowrocket.ink/img/3x-ui-1100993.jpg)

После создания входящего подключения зайдите в него, чтобы добавить клиента:
укажите любой email/пометку, по которым сможете себя опознать, задайте лимит
трафика, лимит IP и дату истечения по необходимости, выберите только что созданное
входящее HY2 в поле «Связанные входящие», убедитесь, что клиент включён, и нажмите
«Создать»:

![Диалог добавления клиента с настройкой трафика, лимита IP и связанного входящего](https://shadowrocket.ink/img/3x-ui-1100994.jpg)

После создания панель сгенерирует для этого клиента персональный QR-код подписки —

информация о подписке — ваши личные учётные данные, никому их не передавайте; я

### 5.2 Включение правила переадресации для port hopping на VPS

Одного включения UDP Hop в панели недостаточно — на уровне файрвола/NAT сервера
также нужно правило, перенаправляющее трафик из диапазона портов перескока на
порт, который реально слушает Hysteria2. Настройте это с помощью `nft` (nftables):

```bash
modprobe nf_tables
modprobe nf_conntrack
modprobe nf_nat
modprobe nft_chain_nat
modprobe nft_redir

nft delete table ip hy2jump 2>/dev/null || true

nft add table ip hy2jump
nft 'add chain ip hy2jump prerouting { type nat hook prerouting priority dstnat; policy accept; }'
nft add rule ip hy2jump prerouting udp dport 20000-50000 redirect to :21327

nft list table ip hy2jump
```

Диапазон портов здесь должен совпадать с тем, что задан для UDP Hop в панели, а
порт после `redirect to` — это порт, который реально слушает входящее подключение
(тот, что вы указали при создании входящего).
